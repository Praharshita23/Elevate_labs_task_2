Superstore Sales Performance Dashboard

Task 2 – Data Visualization and Storytelling (Power BI)

Project Overview

This project presents an interactive Sales Performance Dashboard developed using the Superstore dataset. The dashboard analyzes key business metrics such as sales, profit, quantity sold, and customer segments to generate meaningful business insights through visual storytelling.

Dashboard Features

KPI indicators: Total Sales, Total Profit, Total Quantity Sold, Total Transactions, Average Sales, Average Profit

Category and sub-category level performance analysis

Profit comparison across customer segments

Sales trend analysis over time

Treemap, donut chart, bar charts, and trend visualizations

Interactive slicers for Segment, Category, Ship Date, and Ship Mode

Key Insights

Consumer segment contributes the highest profit.

Office Supplies and Technology categories drive a major portion of total sales.

Copiers, Phones, and Accessories are the top-performing sub-categories.

Standard Class shipping accounts for the majority of transactions.

Suggestions

Focus marketing efforts on the Consumer segment to increase profitability.

Increase promotions for high-performing categories and sub-categories.

Maintain efficient Standard Class shipping operations to meet customer preference.

Tools Used

Power BI
Excel
Power Query (data preparation)
